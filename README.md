# Focus — TV & OTT UX Quiz

A self-contained, responsive English-language learning quiz about TV UX and OTT design.

- 60 scenario-based questions across 10 topics
- Essentials, full quiz, and topic practice
- Study mode with immediate explanations and test mode with a final review
- Scoring, topic breakdowns, missed-question retakes, and downloadable results
- Keyboard controls and browser-local session saving

Open `index.html` directly in a browser to use it offline.

The GitHub Pages site is published from the root of the `main` branch. To update it, replace `index.html` and push to `main`; no build tools or dependencies are required.

Progress is saved separately in each browser and does not sync between devices.
